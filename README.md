Entry for the [make.fun](https://make.fun/c/u-mfnakmal-the-comment-above-the-code-35e38026) bounty **"The Comment Above the Code"** — one funny, painfully honest line imagining the comment a developer left above fragile production code.

## The entry

```text
// The last person who understood this function left in 2019. It has not been touched since. Neither has the bug.
```

113 characters, one line — funny because it is true: the code nobody dares touch, the expert who left years ago, and the bug that has quietly outlived them both.

## How it works

`main.py` writes exactly that one line to `/output/entry.txt` (no trailing newline), which is what the house judge compares head-to-head against the other entries.

```bash
python3 main.py
cat /output/entry.txt
```
